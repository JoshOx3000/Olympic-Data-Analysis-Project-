# 🏅 Olympic Data Analysis Project (Tokyo 2020 & Beijing 2022)

## 📌 Project Overview

This project demonstrates an end-to-end data analysis workflow using Microsoft Excel. The objective was to clean, transform, analyze, and visualize Olympic medal data from the Tokyo 2020 and Beijing 2022 Olympic Games.

The project highlights practical Excel skills commonly used by Data Analysts, including data cleaning, PivotTables, and dashboard creation.

---

## 📊 Dataset

The dataset contains Olympic medal results from:

- Tokyo 2020 Olympic Games
- Beijing 2022 Winter Olympic Games

Each record includes information such as:

- Discipline
- Olympic Games
- Event
- Gender
- Medal Type
- Athlete/Team
- Country
- Country Code

---

## 🛠️ Project Workflow

### 1. Data Cleaning

The raw dataset was cleaned to improve consistency and usability by:

- Correcting inconsistent values
- Standardizing team names
- Replacing missing athlete names for team events
- Removing unnecessary formatting
- Preparing the data for analysis

---

### 2. Data Transformation

The cleaned dataset was transformed by:

- Creating a structured analysis table
- Standardizing text values
- Organizing categorical data
- Preparing fields for PivotTables

---

### 3. Data Analysis

Using PivotTables, the following analyses were performed:

- Athlete vs Team medal counts
- Medal distribution
- Olympic Games comparison
- Event summaries
- Country performance
- Sport/Discipline breakdown

---

### 4. Data Visualization

Interactive charts and PivotCharts were created to visualize:

- Medal distribution
- Athlete vs Team medals
- Country performance
- Olympic event summaries

These visualizations make the data easier to interpret and support data-driven insights.
